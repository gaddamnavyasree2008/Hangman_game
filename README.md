# Hangman Game Using Python

## 📌 Project Description
Hangman Game is a simple text-based word guessing game developed using Python. The player must guess a hidden word one letter at a time. The game allows a maximum of 6 incorrect guesses. It ends when the player guesses the word correctly or runs out of attempts.

## ✨ Features
- Contains 5 predefined words.
- Allows the player to guess one letter at a time.
- Limits incorrect guesses to 6.
- Displays the guessed letters and remaining attempts.
- Shows a winning or losing message.

## 🛠️ Technologies Used
- Python 3
- Python IDLE

## ▶️ How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open `hangman_game.py` in Python IDLE.
4. Press F5 to run the program.
5. Enter one letter at a time to guess the hidden word.

Good guess!
